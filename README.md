# Medical Device Regulatory Analysis

A structured, educational toolkit for organizing regulatory research, risk tables, and evidence plans for medical devices.

The motivating case study is end-stage renal disease and wearable artificial kidney technology, including FDA pathway considerations, benefit-risk reasoning, and clinical translation.

## Included utility

`src/risk_matrix.py` validates a simple hazard table and calculates a transparent pre-control risk score.

```bash
python src/risk_matrix.py examples/sample_risks.csv
```

## Important boundary

This repository is educational and does not provide legal, regulatory, quality-system, or clinical advice. Device classification and submission strategy must be confirmed using current official guidance and qualified experts.

## Public content

Only original summaries and permission-cleared reports should be uploaded. Do not publish confidential design history, clinical, sponsor, or submission materials.
